# CHALLENGE.md

**Status:** RATIFIED 2026-09-16
**Anti-job:** A Challenge is not a Feature Card, not a TEST, not capital, not operating authority.

## Standing rule

```
HERE IS A WORKING MACHINE.
DO NOT COPY IT.
ATTACK IT.
THEN REDESIGN THE OBJECT.
THEN HAND A BUILD SPEC A BOT CAN EXECUTE.
LABEL EVERY UNOBSERVED NUMBER.
```

If a Challenge output agrees with the current mission and only adds features, it has failed — even if the prose is good. Reject for failing *this* commission or adding no incremental value, not for resembling existing work.

## Independence

Material Discovery work requires a separate brief, context, and reviewer. Separate Bot IDs are run-config.

Governor commissions. Challenger executes. Experiment Conductor does not author the Challenge for a lattice it is defending. Examiner does not score the Challenge memo. Intake Auditor admits kernels. Discovery cannot certify itself.

## Packet (required)

1. Working machine named
2. Copy ban
3. Five weaknesses
4. Five missed objects (not five features on the same object)
5. Three models A/B/C — at least one makes the forecast or the inventory unnecessary
6. Assumptions that are probably wrong
7. Hard gates a pretty score cannot outvote
8. Object redesign — one sentence
9. Build spec (files, labeled estimates, human gates, done-condition)
10. Theater list — claimed results that must stay dashes until observed
11. Layman brief

Missing a section = incomplete. Incomplete Challenges are not admitted as commissions.

Estimates and scenarios may appear labeled `[E]`/`[H]`/`[A]`. They are not front-door metrics.

## OS hard gates (travel with every Challenge)

- No invented fills, win rates, ECE, ROIC, or response rates as `[V]`
- Coverage / sample size starts at 0 until Clock clears a tape
- Executable economics use executable prices or contracted fees
- Secrets, order clients, and autodialers stay off the shared computer
- README / INDEX that disagree with the last close = incomplete close

Domain gates live in the domain pack and run-config, not here.

## Done-condition

`records/` or the domain archive holds `CHAL-YYYYMMDD-<slug>.md` with sections 1–11, Auditor stamps on models A/B/C, and theater list applied or Governor-deferred.

Cycle-specific instances (including short-horizon market packs) live in the domain repository, not in this file.
