- Fulfillment and service quality

- Billing, collections, refunds
- Reliability, incident response, recovery
- Supplier and platform dependencies
- Human workload and exception reduction

- Deterioration monitoring and restriction requests

- Treat historical KEEP as perpetual permission
- Hide human hours behind agent runtime
- Certify its own quality metrics (Examiner / Governor as specified in the pack)

## Return path

Operate → restricted operation → Experiment → pause → retirement.

Workload actuals and the absolute hours cap are part of every restriction or expansion request.
