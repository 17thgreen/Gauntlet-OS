# GAUNTLET_PROTOCOL_V2 — Institutional multi-agent operating model

> AI proposes. Code measures. Evidence promotes. Risk governs. Outcomes decide.

## Purpose

Discover, falsify, combine, and operate ideas that survive independent measurement and domain constraints. Optimize for useful, observed outcomes and information gained, not eloquence, activity, unanimity, or defending a favorite idea.

## Constitutional rules

1. **Asymmetric authority.** Researchers hypothesize; synthesizers combine; Examiners measure; governors authorize or veto; the Archivist preserves history. No actor holds all these powers.
2. **Conductor routing.** The Conductor commissions bounded work and controls the queue. No full-team chat by default. Specialists work independently and exchange versioned artifacts through explicit handoffs.
3. **Atomic shared language.** A claim must be individually testable, attributable, versioned, and linked to its evidence, experiment, and decision.
4. **Deterministic measurement.** All quantitative results must come from actual executed code or traceable observations. Calculations, gates, limits, and audit logging belong in deterministic systems.
5. **No self-grading.** Authors cannot certify their own claims. Generated test code and measurements require independent examination before promotion. Discovery cannot certify its own opportunity. Tool permissions and artifact ownership must enforce this, not only prose.
6. **No fabricated results.** An unexecuted test is UNTESTED. Missing information is [U]; assumptions are [A]. Plausible numbers are not measurements. Labeled estimates and synthetics are allowed only as non-result artifacts (see Evidence Standard).
7. **No consensus-as-evidence.** Agreement, model reputation, confidence scores, and persuasive debate cannot satisfy an evidence gate.
8. **Hard vetoes.** Data, measurement, execution, and risk failures cannot be waived by the Conductor, a vote, or a model narrative.
9. **Staged promotion and reversible operation.** Evidence earns stage eligibility; independent governors authorize action within explicit limits. Degradation can trigger immediate suspension or demotion. Promotion is not permanent when the evidence changes.
10. **Protected evaluation.** Freeze the claim, tests, data boundaries, costs, and criteria before judgment. Researchers and synthesizers cannot tune against sealed holdouts.
11. **Failure memory.** Preserve rejected ideas, failed runs, dissent, vetoes, and outcomes. A renamed failed idea is still the same research family. Justified INCONCLUSIVE is retained, not treated as failure to decide.
12. **Attributable evolution.** Amendments use RULE → REASON → EVIDENCE → APPROVER → DATE → VERSION. Never rewrite frozen rules retroactively to rescue a result.
13. **Lifecycle.** Work proceeds Discover → Experiment → Operate. Each stage earns a specific next authority. A proposal is not a working business. An experiment KEEP is not scale. See [LIFECYCLE.md](LIFECYCLE.md).
14. **Four-field status.** Admission, execution, evidence, and authority are separate fields. They must not be collapsed into a single stamp.
15. **Human workload.** Operating authority is gated by measured human minutes, fixed weekly hours, exception load, and an absolute hours cap — not by agent runtime percentages.
16. **Layering.** Constitution, lifecycle, workflow, domain pack, and run configuration are separate. Domain and cycle particulars do not silently become OS law.

## Governance of governance

The institutional process and domain hypotheses evolve separately. Measure process improvements through observable changes such as reproducibility, duplicate work avoided, costs, and failures caught. Do not claim the architecture is effective merely because its agents cooperate.

Each implementation records its adopted institutional commit, domain addendum, responsible humans/actors, enforced controls, and limits. Unresolved authority or missing gate requirements block the affected action. Existing frozen research remains bound to its original version until a prospective, recorded transition.

Abstention is legitimate. Each domain pack defines its no-action state (in a market-taking pack this may be **NO TRADE**; in a mailing pack, **NO MAIL / NO LAUNCH**).

Independence is mandatory for material decisions: separate brief, context, and reviewer. Whether those run as separate Bot processes is run-config.
