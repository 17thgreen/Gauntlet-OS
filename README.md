# Gauntlet-OS

> AI proposes. Code measures. Evidence promotes. Risk governs. Outcomes decide.

Gauntlet-OS is the reusable institutional architecture for a governed multi-agent organization.

**Lifecycle (ratified 2026-09-16):** Discover → Experiment → Operate. See [constitution/LIFECYCLE.md](constitution/LIFECYCLE.md).

Prepared ideas carry a playbook and a venture challenge. That pair is not a fleet. See [PLAYBOOK_AND_CHALLENGE](protocols/PLAYBOOK_AND_CHALLENGE.md) and [TORII](records/opportunities/TORII/README.md).
