# Domain pack template

Adapt the workforce and measurable outcomes while preserving constitutional separation of powers.

## Required binding

- Domain objective, scope, excluded actions and explicit abstention state.
- Institutional repository and adopted commit/version; local domain version.
- Specialist mandates and allowed inputs.
- Named Conductor, Archivist, independent Examiner, Prosecutor and required governors.
- Data manifests: provenance, acquisition time, quality, hashes, transformations, timing, permitted use and access boundaries.
- Atomic Idea extensions defining a precise action and falsification.
- Exact promotion/demotion states, minimum samples, deterministic thresholds and stop/restart rules.
- Independent replication context and prospectively collected forward outcomes.
- Operational/execution constraints, approved budgets/exposure and veto authorities.
- Research/validation/sealed evaluation partition and access enforcement.
- Trial accounting, versioning, amendment approver and failure-memory retrieval.
- Storage, audit, backup and reproducibility locations.
- Evidence that the required controls actually operate.

Mark unbound fields [U]. A required unknown blocks the affected test, promotion or operation; it does not grant permission. Domain thresholds must be approved before judging outcomes.

## Portability

Translate crypto-specific terms to domain equivalents without deleting safeguards. “Micro capital” may become a bounded pilot; “NO TRADE” may become no submission/no launch. Document each mapping and its gate.

Keep implementation code, operational state and detailed domain evidence in the domain's own repository. Point back to the adopted Gauntlet-OS commit. Domain extensions cannot silently weaken constitutional prohibitions or retroactively change frozen experiments.
